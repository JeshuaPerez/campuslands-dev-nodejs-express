# Ejercicio 28 intermedio - coleccion de ejemplos HTTP (Jeshua Perez)

## Que hace

Tematica battle royale. CRUD basico de jugadores. `requests.http` (formato
REST Client de VS Code) trae ejemplos listos para ejecutar: caso feliz,
un 400 y un 404.

## Como ejecutar

```bash
npm install
npm run dev
```

Con la extension "REST Client" de VS Code, abrir `requests.http` y correr
cada peticion con el boton "Send Request".

## Tests

```bash
npm test
```
