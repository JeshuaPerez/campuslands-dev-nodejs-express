# Ejercicio 23 intermedio - testing con node:test (Jeshua Perez)

## Que hace

Tematica soldadura. `Inventario` (clase con campo privado `#electrodos`)
controla el stock de electrodos. Los tests usan `describe` + `beforeEach`
del runner nativo de Node para arrancar cada caso con estado limpio.

## Como ejecutar

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```
