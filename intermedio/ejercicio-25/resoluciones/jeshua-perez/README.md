# Ejercicio 25 intermedio - testing de rutas (Jeshua Perez)

## Que hace

Tematica videojuegos RPG. CRUD de inventario (`GET`, `POST`, `DELETE`).
Los tests usan `before`/`after` para levantar el servidor una sola vez en
un puerto efimero y probar las rutas reales con `fetch`, en vez de probar
funciones sueltas.

## Como ejecutar

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```
