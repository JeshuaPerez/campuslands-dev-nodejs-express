# Ejercicio 24 intermedio - testing de servicios (Jeshua Perez)

## Que hace

Tematica formulas quimicas. `crearFormula(repositorio, datos)` recibe el
repositorio por parametro (inyeccion simple), asi los tests le pasan un
repositorio falso en memoria en vez de tocar el modulo real.

## Como ejecutar

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```
