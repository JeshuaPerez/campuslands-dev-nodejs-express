# Ejercicio 25 - respuestas HTTP correctas (Jeshua Perez)

## Que hace

Tematica videojuegos RPG. `src/controllers/personajes.controller.js` usa el
codigo HTTP correcto para cada caso: `200` (ok), `201` (creado), `204` (sin
contenido tras eliminar), `400` (datos invalidos), `404` (no encontrado) y
`409` (nombre de personaje duplicado).

## Como ejecutar

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```
