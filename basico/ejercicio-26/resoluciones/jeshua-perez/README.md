# Ejercicio 26 - codigos de estado (Jeshua Perez)

## Que hace

Tematica shooters competitivos. `POST /partidas` (201), `GET /partidas/:id`
(200 o 404) y `PATCH /partidas/:id/finalizar` (200, o 409 si ya estaba
finalizada).

## Como ejecutar

```bash
npm install
npm run dev
```

## Tests

```bash
npm test
```
