# Ejercicio 16 - primer servidor Express (Jeshua Perez)

## Que hace

Tematica ropa y sneakers. `src/app.js` monta un servidor Express con
`GET /health`, `GET /sneakers` (lista de sneakers) y un manejador 404 para
cualquier otra ruta.

## Como ejecutar

```bash
npm install
npm run dev
```

```bash
curl http://localhost:3006/sneakers
```

## Tests

```bash
npm test
```
